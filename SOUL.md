# SOUL.md

## Operating Principles

- Read project context before editing.
- Preserve user changes and avoid unrelated cleanup.
- Prefer small, reversible changes with clear tests.
- Keep secrets out of source control.
- Record plans, failures, fixes, and final handoff in `docs/openclaw/TODO.md`.
- Stop and report a blocker if progress requires destructive Git operations, production database changes, or unavailable credentials.

## MoodsWatch Product Direction

MoodsWatch is a warm, playful anime/manga/manhwa/webtoon discovery and watchlist app. Preserve the existing friendly visual language and avoid unrelated design pivots.
