# Root Artifacts Archive

This folder contains old scratch files that used to live in the repository root.

- `logs/`: previous Vite/build/test run logs and PID files.
- `audit/`: saved local audit JSON outputs.
- `sql/`: one-off SQL scratch files.
- `css/`: one-off CSS scratch files.
- `stitch/`: temporary visual stitching/reference material.

These files are kept for reference only. Current source code, tests, scripts, and production assets live outside this archive.
